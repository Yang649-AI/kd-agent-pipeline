# 项目开发记录

本记录用于说明 `kd_agent_pipeline` 每轮开发做了什么、增加了哪些工具或模块，以及实验指标如何变化。当前先补齐已经完成的计算机方向实验；后续新增实验时继续追加。

## 指标说明

- Token 消耗：记录平均输入、输出、总 Token；缺少细分时记录平均总 Token。
- 延迟/吞吐：吞吐按 `平均总 Token / 平均延迟` 估算，仅用于本地脚本间相对比较。
- 准确率：当前自动评测主要使用“答案关键词命中率/关键词召回率”近似表示。
- 幻觉率：当前以“无引用生成率/无证据回答率”近似统计。
- Hit@5：只有带标准证据标注的数据集才能严格计算；早期 smoke test 未记录时标为“未记录，需复测”。
